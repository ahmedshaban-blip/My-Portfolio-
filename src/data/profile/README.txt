================================================================================
                دليل تعديل البيانات الشخصية  (src/data/profile)
================================================================================
كل حاجة الزائر بيشوفها عنك موجودة هنا كملفات JSON عادية. القاعدة الواحدة:
عدّل الـ JSON — مش محتاج تفتح أي component عشان تغيّر كلمة أو لينك أو تاريخ.

الـ components بتستورد من "@/data/profile" (ملف index.ts)، مش من الـ json
مباشرة. فلو ضفت حقل جديد: ضيفه في الـ json + ضيفه في الـ schema اللي تحته في
validate.ts، وبعد كده الـ TypeScript هيقولك على كل مكان ناقص فيه الحقل.


--------------------------------------------------------------------------------
1) الملفات — كل ملف بيمثّل إيه
--------------------------------------------------------------------------------
identity.json     الاسم (first/last/display/legal)، المسمى الوظيفي، الشغل الحالي،
                  ونصوص الهيرو (greeting / tagline / intro / availability) + الصورة.
contact.json      الإيميل + التليفون (display و e164) + رقم الواتساب ورسالته.
social.json       لينكات GitHub و LinkedIn + هاندل X (تويتر).
location.json     المدينة والدولة والتوقيت، و origin (بلد الأصل)، وإمكانية الانتقال،
                  وworkModes (remote/on-site).
about.json        نص About Me (bio)، كروت الـ 4 highlights، والأرقام المميزة (stats).
experience.json   الخبرات الوظيفية (roles) + قايمة الكورسات (courses).
education.json    الدرجة العلمية + التقدير.
skills.json       كاتيجوري المهارات + أيقونة كل كاتيجوري.
languages.json    اللغات (مش معروضة في الموقع حاليًا — جاهزة لو حبيت تضيفها).
cv.json           بيانات الـ CV: اسم الملف على Cloudinary، اسم التحميل، والفالباك المحلي.


--------------------------------------------------------------------------------
2) تعديل / إضافة / حذف
--------------------------------------------------------------------------------
- تعديل كلمة: افتح الملف وغيّر النص بين علامات التنصيص. خلّي بالك من الفاصلة ( , )
  في آخر كل سطر وقبل القوس الأخير.
- إضافة عنصر (سكيل، كورس، خبرة، highlight): انسخ العنصر اللي قبله، افصله بفاصلة،
  وغيّر القيم. المصفوفة تقبل أي عدد.
- حذف عنصر: امسح الكائن بالكامل **مع الفاصلة اللي بعده أو قبله** — فاصلة زيادة أو
  ناقصة تكسر الملف.
- أرقام: خليها أرقام من غير تنصيص (visibleCount: 5). النصوص دايمًا بين " ".
- الجمل الطويلة في about.json (bio) مقسّمة أجزاء: كل جزء فيه text، ولو عايزه
  عريض ضيف "strong": true. مثال: [{"text":"I hold a "},{"text":"Bachelor","strong":true}]
- نص الهيرو (tagline) بيستخدم "accent": true بدل "strong"، وفيه جزء "ariaHidden": true
  للإيموجي. سيبهم زي ما هما لو مش محتاج تغيير.


--------------------------------------------------------------------------------
3) القيم الحساسة للاسم  (لو غيّرت الاسم غلط، اللينك بيكسر في صمت)
--------------------------------------------------------------------------------
(أ) cv.json — الأهم، وزي ما بتشتغل حاليًا:
    - cloudinaryPublicId : لازم يطابق اسم الملف المرفوع على Cloudinary بالحرف
      (flutter_cv.pdf و frontend_cv.pdf). غيّره = الملف مش هيتلاقى.
    - fileName : الاسم اللي المستخدم بيشوفه وهو بينزّل (مش لازم يطابق حاجة).
    - fallbackUrls : مسارات ملفات للطوارئ بتتقرأ من فولدر public/.
      أي مسار تحطه هنا لازم يكون فيه ملف بنفس الاسم جوّه public/ بالحرف،
      وإلا الفالباك نفسه هيفشل. الترتيب مهم: بيجرّب الأول فالأول.
    - الـ upload presets مش هنا — دول في متغيرات البيئة (.env) لأنهم أسرار.
    - الملفات الحالية: public/ahmed-shaban-flutter-cv.pdf
                       public/ahmed-shaban-frontend-cv.pdf
    - ملف cv.json ده هو المصدر الوحيد لتلات أماكن: الموقع نفسه، ومسار التحميل
      api/download-cv.ts، ومسار توقيع الرفع api/cloudinary-signature.ts.
      التلاتة بيقروا منه مباشرة، فتغيير الاسم هنا بيسري على التلاتة مع بعض.

(ب) icon في skills.json و about.json:
    لازم يكون واحد من الأسماء دي بالحرف:
      smartphone | globe | database | code2 | terminal | globe2
    أي اسم تاني = أيقونة فاضية. الأسماء مربوطة في:
      src/components/Skills.tsx  (خريطة ICONS)
      src/components/About.tsx   (خريطة ICONS)

(ج) identity.json → hero.photo:
    base  = "/images/personal-image"  (بدون المقاس)
    widths = [320, 640, 960]  → لازم يكون فيه ملفات بالاسم ده في public/images/:
            personal-image-320.webp و -640 و -960
    تنبيه: نفس المسارات مكررة في index.html (وسم preload). لو غيّرت الصورة،
      غيّرها في المكانين (هنا وفي index.html) وإلا هتحمّل صورة غلط مقدمًا.

(د) index.html مش بيتقرأ من JSON:
    <title> و description و author و og:* و twitter:site لسه مكتوبين يدوي في
    index.html (أحسن للـ SEO). لو غيّرت اسمك أو مسمّاك الوظيفي، حدّثهم هناك كمان.


--------------------------------------------------------------------------------
4) التحقق (لو كسرت حاجة)
--------------------------------------------------------------------------------
- شغّل: npm run dev
- لو أي ملف مش مطابق للـ schema، هيطبعلك في console المتصفح رسالة بالشكل:
      [profile] src/data/profile/xxx.json does not match its schema.
          • الحقل: سبب المشكلة
- التحقق ده بيشتغل في التطوير بس ومش بيتحطّ في نسخة الإنتاج أصلًا.
- كمان: npm run build بيفشل لو غيّرت شكل البيانات بدون تحديث validate.ts.


--------------------------------------------------------------------------------
5) مكان التوحيد اللي حصل
--------------------------------------------------------------------------------
- المكان بقى مصدر واحد: location.json. الهيرو والكونتاكت بيقروا نفس القيم.
  المعروض حاليًا: Cairo, Egypt (GMT+2) — و origin = Minya محفوظة للاستخدام.
  لو عايز ترجّع Minya كمدينة معروضة: غيّر "city" لـ "Minya" في مكان واحد بس.
- الإيميل والتليفون والواتساب كانوا متكررين في 3 ملفات — خلاص مصدرهم contact.json.
