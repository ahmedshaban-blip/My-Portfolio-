# Context Glossary

## Animation Experience

- **Page-load entrance**: The initial animation shown when the portfolio first opens, focused on revealing the hero content without a preloader or splash screen.
- **Scroll reveal**: A one-time animation that reveals content as it first enters the viewport; revealed content does not re-animate when revisited.
- **Navigation animation**: Smooth scrolling between portfolio sections plus an active navigation indicator; it does not include animated page or section transition overlays.
- **Subtle professional motion**: Motion style based on restrained fade, slide, scale, and light stagger effects; it avoids heavy scroll-linked visual effects.
- **Mobile motion**: Mobile devices still receive animations, but with lighter/faster variants and reduced interaction effects compared with desktop.
- **90Hz performance target**: Animations should remain smooth on high-refresh displays by prioritizing lightweight, transform-based motion and avoiding unnecessary runtime work.
