# Ahmed Shaban's Developer Portfolio
[![Ask DeepWiki](https://devin.ai/assets/askdeepwiki.png)](https://deepwiki.com/ahmedshaban-blip/My-Portfolio-)

<br>

This repository contains the source code for my personal portfolio website, built to showcase my skills and projects as a Flutter and Front-end Developer. The site is a dynamic single-page application crafted with a modern tech stack, emphasizing clean design, responsiveness, and a great user experience.

## ✨ Features

*   **Hero Section:** A welcoming introduction with links to my social profiles and a downloadable CV.
*   **About Me:** A detailed look into my academic background, internship experience, and passion for development.
*   **Technical Skills:** A categorized list of my competencies in both Flutter (mobile) and React (web) development.
*   **Featured Projects:** An interactive tabbed view of my key projects, complete with descriptions, tech stacks, and links to GitHub repositories and live demos.
*   **Experience & Education:** A timeline of my professional internship at the Information Technology Institute (ITI) and my Computer Science degree from Minya University.
*   **Contact Form:** An easy-to-use form for visitors to get in touch, along with direct links to my email and phone.
*   **Responsive Design:** The entire layout is optimized for desktops, tablets, and mobile devices.
*   **Smooth Scrolling & Animations:** Subtle animations and smooth navigation enhance the user experience.

## 🛠️ Tech Stack

*   **Framework:** React
*   **Build Tool:** Vite
*   **Language:** TypeScript
*   **Styling:** Tailwind CSS
*   **UI Components:** shadcn/ui
*   **Routing:** React Router
*   **Backend Integration:** Supabase client for potential future features.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

Make sure you have Node.js and `npm` (or a compatible package manager) installed on your system.

### Installation

1.  **Clone the repository:**
    ```sh
    git clone https://github.com/ahmedshaban-blip/my-portfolio-.git
    ```

2.  **Navigate to the project directory:**
    ```sh
    cd my-portfolio-
    ```

3.  **Install dependencies:**
    ```sh
    npm install
    ```

4.  **Start the development server:**
    ```sh
    npm run dev
    ```

The application will be available at `http://localhost:8080`.

### Other Scripts

*   **Build for production:**
    ```sh
    npm run build
    ```

*   **Lint the code:**
    ```sh
    npm run lint
    ```

*   **Preview the production build:**
    ```sh
    npm run preview
